🗄 Collection Data

Collection Hub data lives in the database. Seed it from the old JSON files, download a backup, or restore from one.

Seed from repo files

Copies every collection-hub/*-backup.json into the database, replacing what's there. Safe to re-run until the old files are deleted.

Backup

Downloads everything currently in the database as one JSON file.

Restore

Replaces the database with the contents of a backup file downloaded above.
